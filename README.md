# KDTIVI releases

Sideloadable builds of KDTIVI for Apple TV, iPhone and iPad. This repository holds releases only, no source code.

Install guide: https://kdtapps.com/sideload/

## Updating Apple TV with atvloadly

Add `kdthomas2121/kdtivi-releases` as a GitHub source in [atvloadly](https://github.com/bitxeno/atvloadly), choose the `tvOS` file, and atvloadly will offer each new release.

Each release has two files: `KDTIVI-tvOS-<version>.ipa` for Apple TV and `KDTIVI-iOS-<version>.ipa` for iPhone and iPad.
